# Checklist de ronda com torneira sentinela

**Projeto:** plano-contingencia-agua · **Versão:** 0.1 — rascunho para revisão técnica · **Data:** 2026-10-02

> **Para que serve.** Hoje o único alarme da água foi o ocupante abrindo a torneira e vendo a cor. Este checklist coloca **a equipe de ronda 24h** para ver a água **antes** do ocupante, usando o corante do tratamento (rosa = água gelada; azul = reúso, no condomínio de referência; **cores por condomínio: ver a ficha**) e alguns pontos fixos.
>
> **O que a ronda faz:** olha, mede o que o kit permite, registra e **aciona**. **Não opera** química, quadro, gerador nem válvula que não seja da sua habilitação.

**Torneira sentinela:** ponto de consumo real escolhido na **ficha** (por prumada ou setor ⚠), de preferência **distante da entrada** e que seja **usado**. Local, andar e foto ficam na ficha.

**Frequência:** definida na ficha ⚠. Sugestão do projeto: **a cada ronda**; e **diária, com registro**, por um período após qualquer incidente (ver Cenário 1, Fase 5).

## 1. Torneira sentinela

Abra **devagar** e deixe correr até estabilizar (tempo definido na ficha ⚠). Olhe a água **em recipiente transparente, contra fundo branco**.

## 2. Pontos fixos da ronda

| # | Onde | Verifique | OK | Anomalia | Obs. |
|---|---|---|---|---|---|
| 2.1 ★ | **Casa de máquinas / reposição do chiller e da torre** | Há **mangueira, jumper ou ligação provisória** conectada? (**Sim = anomalia, acionar nível 1**) | | | |
| 2.2 | Casa de máquinas | Vazamento visível no circuito (válvulas, flanges, bombas)? Nível do tanque de reposição normal? | | | |
| 2.3 | Casa de máquinas / torre | Bacia de contenção de produto químico **seca e íntegra**? Alarme ativo? | | | |
| 2.4 ★ | **Reservatórios** (cisterna, caixa superior) | **Tampa fechada**, lacre intacto, **ladrão com tela**, sem infiltração ou sujeira visível? Nível conforme? | | | |
| 2.5 | **Bombas** (recalque, drenagem, esgoto) | Sem alarme, sem ruído ou vibração anormal? **Quadro em automático**? | | | |
| 2.6 | **Subsolo** | Sem água no piso? **Bomba de drenagem** funcionando? | | | |
| 2.7 | **Gerador** | Painel sem alarme? **Nível de diesel** conforme a ficha? Chave em automático? | | | |
| 2.8 | **Bomba de incêndio** | Quadro em **automático**, sem alarme? **Válvulas** abertas? Pressão da rede normal? | | | |
| 2.9 | **Reúso** | Tubulação e pontos **identificados**? **Interligação** com o potável lacrada? | | | |

★ = ponto crítico. **Sim** em 2.1, **não** em 2.4 (tampa aberta, sem tela, infiltração) ou **cor de traçador** em 1.1 aciona o nível 1 **na hora**.

## 3. O que fazer com o que a ronda viu

| O que a ronda viu | Cenário a usar | Primeira ação |
|---|---|---|
| **Cor do traçador** (rosa ou azul) na sentinela, ou **mangueira/jumper conectado** | **Cenário 1** — contaminação cruzada | **Suspender o consumo**, fechar a fonte, **acionar o nível 1** |
| Água suja, turva, com odor ou cloro baixo, **sem traçador** | **Cenário 3** — água fora do padrão | Medir, coletar **antes** de descarregar, acionar o nível 1 |
| Falta de água, pressão caindo, reservatório baixo | **Cenário 2** — falta de água | **Fechar a reposição ao potável do chiller/torre**, acionar o nível 1 |
| Alarme de bomba, queda de energia, gerador ou bomba de incêndio com falha | **Cenário 5** — falha de bomba ou de energia | **Segurança elétrica primeiro**; não manobrar sem habilitação; acionar o nível 1 |
| Tampa aberta, animal, sujeira ou infiltração no reservatório | **Cenário 9** — contaminação do reservatório | Isolar, **não entrar** sem permissão de trabalho, acionar o nível 1 |
| Vazamento ou alagamento | **Cenário 4** — vazamento e alagamento | Conter, **desenergizar com habilitado**, acionar o nível 1 |
| Derrame de produto químico | **Cenário 8** — falha do tratamento químico | Afastar pessoas, **FISPQ**, não lavar para o ralo, acionar o nível 1 |

> Em dúvida entre dois cenários, **siga o mais restritivo** e acione o nível 1.
