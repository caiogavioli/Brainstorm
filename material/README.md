# material/

Insumos que o usuário trouxe para este branch. **Sem dados de condomínio** — só os prompts genéricos que ele já usava.

## prompts-anteriores/

Os quatro prompts que o usuário usava em outras IAs para analisar concorrências. Os três últimos são texto extraído de `.docx` (tabelas viram texto corrido); o conteúdo é o original.

| Arquivo | Origem | O que é |
|---|---|---|
| `prompt-mestre-v2-generico.md` | `.md` anexado | "Prompt Mestre v2.0" genérico para qualquer documento (12 seções, muitos placeholders) |
| `prompt-mestre-2.0-executivo.md` | `PROMPT_MESTRE_2.docx` | Versão executiva/decisória — BLUF, citação obrigatória, omite seção vazia |
| `prompt-mestre-3.0-exaustivo.md` | `PROMPT_MESTRE_3.docx` | Versão exaustiva para conselho/assembleia — validação matemática, SWOT, GUT, 5W2H |
| `prompt-mestre-inner-ai-propostas.md` | `PROMPT_MESTRE_INNER_AI.docx` | Específica para propostas de fornecedores — pergunta contexto antes, modo Essencial/Completo, notas ponderadas |

**Atenção:** arquivos de concorrências reais (mapas de cotação, propostas, contratos) **nunca** entram neste repositório. Ficam no OneDrive.
