# P-001 — Catálogo de produtos de impressão 3D

## Em uma frase
Não existe um catálogo organizado dos produtos que são impressos em 3D.

## Como é hoje
Os modelos ficam num site de repositório de itens para impressão 3D, organizados
em pastas de categoria dentro da conta do usuário nesse site. Cada item tem
foto(s) prontas, sem tratamento necessário. Não existe hoje nenhum documento
ou ferramenta que junte essas informações num catálogo apresentável.

## Frequência e volume
- Acontece: coleção estável, com inclusão de novos produtos sob demanda
- Tempo gasto por vez: <a levantar>
- Volume: ~15 categorias, até ~80 produtos por categoria (algumas com menos)

## Quem sofre
O usuário, na hora de mostrar/vender os produtos para clientes.

## O que já foi tentado
Nada ainda — hoje a apresentação é informal, via Instagram simples. Nenhuma
ferramenta de catálogo (Notion, Canva etc.) está em uso.

## Como saberíamos que resolveu
Existe um PDF por categoria (ou um PDF geral navegável) pronto para enviar no
WhatsApp, com foto(s), descrição e tamanho de cada produto — sem preço.

## Restrições conhecidas
- Sem preço no catálogo, por enquanto.
- Saída principal: PDF para WhatsApp.
- Manutenção: o próprio usuário, sozinho ou com automação.
- Fonte dos dados (fotos/descrições) é o site de repositório de modelos 3D —
  ainda não definido como extrair de lá para o catálogo.
